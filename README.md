# HookhaGame
🪔 Caliente — Hookah Space Shooter
A pixel-art space shooter where you pilot a hookah through waves of enemies. Dodge incoming fire, blast your way through escalating waves, and survive as long as you can.

🎮 Gameplay

Shoot enemies before they reach you
Dodge incoming projectiles
Survive increasingly difficult waves
Track your score and remaining lives in real time


🚧 Current Status
In Development — Core mechanics are functional. The following features are still being worked on:

 Flavour power-up system (Mint, and more to come)
 Special effects per flavour
 Additional enemy types
 Sound & music
 Main menu & game over screen


🛠️ Built With

Engine: Unity
Language: C#
Art Style: Pixel art
